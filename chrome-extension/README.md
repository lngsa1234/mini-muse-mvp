# Mini Muse Browser Bridge

This development extension lets Mini Muse work with the last website tab you used. It does not access passwords, browser history, or saved payment details.

## Install locally

1. Open `chrome://extensions` and turn on **Developer mode**.
2. Choose **Load unpacked** and select this `chrome-extension` folder.
3. Open the extension and choose **Enable browser control**.
4. Visit a job site, then return to Mini Muse and ask it to read the page or fill a form.

Mini Muse can read a page. Filling fields and clicking buttons always go through its approval card. The extension is not packaged or published to the Chrome Web Store.
